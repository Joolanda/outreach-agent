# Outreach Agent

An AI-supported outreach workflow built as a hands-on learning project to explore lead sourcing, structured data handling, and personalized message generation.

## Overview

This project explores how AI can support outreach workflows by combining external tools and LLM-based assistance into one lightweight process.

The workflow uses:
- **Claude / Claude CoWork** for AI-assisted reasoning and message drafting
- **Apollo** for lead sourcing
- **Airtable** for structured contact and workflow management
- **Gmail** for communication and outreach execution

The goal was to better understand how these tools can work together in a practical outreach use case.

## Project Background

This repository documents my implementation of an AI-supported outreach workflow based on a public tutorial, which I adapted to my own job-search and outreach use case.

I followed the tutorial steps closely and used the project as a practical exercise to learn more about:
- AI-assisted outreach workflows
- tool integration
- structured workflow design
- personalized communication support with LLMs

## Features

- Organize outreach targets and company/contact information
- Support lead sourcing and structured tracking
- Assist with message drafting and personalization
- Connect multiple tools into one practical workflow
